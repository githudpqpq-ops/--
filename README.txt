# Nomad Stories — Путешествия по Казахстану

## 1. Цель сайта

**Nomad Stories** — это информационный веб-сайт, посвящённый путешествиям по Казахстану. Главная цель проекта — познакомить пользователей с красивыми природными местами, культурными достопримечательностями, интересными маршрутами и традициями Казахстана.

Сайт помогает путешественникам находить новые направления для отдыха, читать истории о путешествиях, изучать полезные советы и предлагать собственные маршруты. Проект направлен на популяризацию внутреннего туризма и знакомство с природным и культурным наследием страны.

## 2. Целевая аудитория

Сайт предназначен для следующих категорий пользователей:

- **Туристы и путешественники** — люди, которые хотят открыть новые места Казахстана.
- **Молодёжь и студенты** — пользователи, интересующиеся активным отдыхом, природой и приключениями.
- **Любители природы и фотографии** — люди, которым интересны горы, озёра, каньоны, степи и живописные пейзажи.
- **Любители истории и культуры** — пользователи, желающие узнать больше о традициях и культурном наследии Казахстана.
- **Организаторы путешествий** — люди, которые ищут идеи и маршруты для поездок.

## 3. Основные разделы сайта

### Главная страница
Знакомит посетителей с проектом Nomad Stories, содержит название сайта, краткое описание его идеи и поле поиска направлений для путешествий.

### Популярные истории
Раздел с историями о путешествиях, природных достопримечательностях, культурных особенностях и полезных рекомендациях для туристов. Пользователь может выбирать истории по категориям.

### Популярные направления
Раздел с фотографиями и описаниями интересных мест Казахстана, включая Алматы, Бурабай, Чарынский каньон, Мангистау и Кольсайские озёра.

### Советы для путешествий
Содержит рекомендации по подготовке к поездкам, выбору необходимого снаряжения, планированию маршрутов и бережному отношению к природе.

### Предложить маршрут
Форма, с помощью которой пользователь может описать собственный маршрут, указать место путешествия, продолжительность поездки, поделиться историей и оставить контактный email.

### Подписка и подвал сайта
Содержит навигационные ссылки, краткую информацию о проекте и форму подписки для получения новых историй и идей для путешествий.

## 4. Функциональные возможности

- Адаптивный дизайн для компьютеров, планшетов и мобильных устройств.
- Навигация между разделами сайта.
- Поиск историй по ключевым словам.
- Фильтрация историй по категориям.
- Карточки популярных туристических направлений.
- Автоматическое заполнение поля места путешествия при выборе направления.
- Проверка обязательных полей и правильности формата email.
- Форма предложения маршрута.
- Форма подписки на новости и новые истории.
- Плавная прокрутка и визуальные анимации.

**Примечание:** формы в текущей версии работают на стороне браузера и демонстрируют обработку пользовательского ввода. Для реальной отправки данных требуется подключение серверной части или внешнего сервиса.

## 6. Описание файлов репозитория

| Файл | Назначение |
|---|---|
| `index.html` | Основная HTML-разметка сайта: шапка, главный экран, истории, направления, советы, формы и подвал. |
| `style.css` | Стили сайта: цвета, шрифты, размеры, расположение блоков, карточки, адаптивность и анимации. |
| `script.js` | JavaScript-логика: мобильное меню, поиск, фильтрация историй, заполнение поля направления и обработка форм. |
| `README.md` | Документация проекта: цель, аудитория, структура сайта, функциональные возможности и описание файлов. |

## 7. Используемые технологии

- **HTML5** — создание структуры и содержимого страниц.
- **CSS3** — оформление элементов, адаптивная вёрстка и анимации.
- **JavaScript** — интерактивность и обработка действий пользователя.
- **Google Fonts** — подключение шрифтов.
- **Unsplash** — внешние фотографии для оформления сайта.
- **Visual Studio Code** — среда разработки.

## 8. Запуск проекта

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в Visual Studio Code.
3. Откройте файл `index.html` в браузере.
4. Для удобной разработки рекомендуется использовать расширение Live Server.

Для загрузки внешних фотографий и шрифтов требуется подключение к интернету.
