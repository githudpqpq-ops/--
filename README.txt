NOMAD STORIES — проект для Visual Studio Code

Файлы:
- index.html — разметка страницы
- style.css — стили и адаптивная версия
- script.js — меню, поиск/фильтры и обработка форм

Как запустить:
1. Распакуйте архив в отдельную папку.
2. Откройте папку в Visual Studio Code.
3. Откройте index.html в браузере. Удобнее использовать расширение Live Server.
4. Для фотографий и шрифтов нужен интернет: используются внешние изображения Unsplash и Google Fonts.

Важно:
Формы в этом варианте работают на стороне браузера: они проверяют заполнение и показывают сообщение, но пока не отправляют данные на почту/сервер. Для настоящей отправки нужно подключить сервер или сервис форм.
Чтобы добиться точного совпадения с исходным макетом по пикселям, нужны исходные скриншоты/файлы стилей Tilda. В этом проекте сохранены доступные из страницы разделы, тексты и идея, а визуальная реализация создана заново.
